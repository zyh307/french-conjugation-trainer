# 法语变位器

面向日常学习与复习的法语动词变位工具，提供 Windows 电脑版和 Android 手机版。支持离线练习、分时态查词、收藏管理与学习记录分享。

## 下载与安装

前往 [发布页](https://github.com/zyh307/french-conjugation-trainer/releases/latest) 下载对应版本。

| 平台 | 系统要求 | 安装方式 |
| --- | --- | --- |
| **电脑版 · Windows** | Windows 10 / 11，64 位 | 下载 ZIP，完整解压后双击“启动法语变位器.bat” |
| **手机版 · Android／安卓** | Android 8.0 及以上 | 下载 APK，在手机上打开安装 |

电脑版内置运行环境，无需安装 Node.js、Python 或其他依赖。程序在默认浏览器中打开，使用期间保持启动窗口运行。请勿直接在压缩包内启动。

安卓旧版用户可直接覆盖安装；保留应用数据即可延续学习记录。

## 功能

- **三级词表、三种时态**：必会、常用、生僻词表，覆盖现在时、复合过去时和未完成过去时。
- **分组学习**：每组三个动词，先完成掌握度判断，再进入练习；判断卡附中文常用义。
- **循序练习**：同一动词按“选择 → 反向 → 填空”推进。不同动词随机穿插，答错后保持当前题型重试。
- **练习辅助**：各题型附中文释义；短词和不规则变位仅提示答案长度，常规词形提供有效词干与后缀长度。
- **查词专练**：查看完整变位，按动词和时态立即练习，完成后计入已背。
- **三本分流**：每个“动词＋时态”只能属于练习本、复习本、已会本之一。选择“熟悉”直接进入已会本，不再安排复习。
- **灵活调整**：练习中可随时加入复习本或已会本，转移前确认。复习本和已会本可放回练习本优先练习，并保留其他词条的进度。
- **长期掌握**：完整练完后进入复习本，已背满 30 天自动转入已会本；再次专练保留原日期和归属。
- **收藏列表**：按动词和时态收藏，支持单个练习、一键练习，记录最近完成时间及次数。
- **复习与错题**：按间隔安排复习，保存错题、学习进度与统计。
- **每日目标**：可设置每天 1–100 个动词的目标，按当天完成的不同动词数计数。
- **分享卡片**：展示累计与今日背词，提供 15 句中法双语名言、随机换句、多款封面及自选图片，支持保存与分享。
- **外观与操作**：紧凑的玻璃质感界面，支持浅色、深色、跟随系统及键盘快捷操作。

## 学习规则

常规学习先展示本组三个动词的变位，并完成全部掌握度判断，再生成练习题。同一动词须完成当前题型的全部人称，才进入下一题型；题型可在偏好设置中调整。

复习本在第 2、4、7、15 天安排复习，第 30 天及之后自动转入已会本。旧版完整已背词条保留原学习日期，达到 30 天的词条自动归入已会本；未完成全部人称的词条继续留在练习本。收藏独立于学习归属，同一动词的同一时态只收藏一次。

练习进度按已确认的实际任务计数。未判断的动词只计掌握度判断卡；选择“有点印象”或“还不熟悉”后即时加入该词需要的练习题，并同步更新进度条。答题后立即显示最新完成数，重新打开练习时重新核对总题数。

单词专练与收藏练习直接进入“选择 → 反向 → 填空”，每个时态独立记录。再次练习已背词不会重置其掌握日期。放回的词安排在当前组之后、后续新词之前。

每日目标与分享统计按动词原形去重。同一动词当天练习多个人称、多种时态或重复练习，只计一次；完成到期复习也计入当天。

## 数据与更新

学习记录保存在本机，电脑与手机暂不自动同步。

- **电脑版**：记录位于程序目录的 `data/` 文件夹。更新时将原有 `data/` 复制到新版目录；备份时可复制整个文件夹。
- **手机版**：记录保存在应用本地。覆盖安装可保留记录；卸载或清除应用数据会删除本机记录。

电脑版服务仅监听 `127.0.0.1:8765`，同时运行一个实例。分享封面和卡片在本机处理。

| 快捷键 | 操作 |
| --- | --- |
| Ctrl / ⌘ + K | 搜索动词、快速跳转 |

| 1–6 | 选择答题选项 |
| Enter | 确认答案、继续下一题 |

## 兼容性

Windows 运行包已完成独立解压与内置环境运行验证。Android 安装包已通过签名校验，安卓真机兼容性尚待验证。

<details>
<summary>开发与构建</summary>

源码开发需要 Node.js 20.19+ 和 Python 3.10+。

```powershell
npm install
npm start
```

默认地址为 `http://127.0.0.1:8765`。开发模式执行 `npm run dev`，访问 `http://127.0.0.1:5173`。可通过 `CONJUGAISON_PYTHON` 指定 Python 路径。

```powershell
npm test
npm run test:device
npm run build
npm run build:desktop
npm run build:apk
```

Windows 运行包需在 Windows 64 位 Python 环境构建。安卓构建需配置 Android SDK Build Tools 35、API 35 和 JDK；后续更新应保留本机签名密钥。

浏览器交互检查可执行 `npx playwright test`，需安装 Microsoft Edge。测试使用独立临时数据目录。

</details>

<details>
<summary>项目结构</summary>

| 文件或目录 | 用途 |
| --- | --- |
| `src/` | 应用界面、手机离线逻辑和分享卡片 |

| `名言出处.md` | 法语名言来源 |

`data/`、开发缓存和签名密钥不纳入版本管理。原版 PyQt 界面保存在 `original_gui.py`。

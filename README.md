# 法语变位器 3.0 · Conjugaison

法语变位练习器的 Liquid Glass 视觉重构。React 界面搭配原版 Python 学习核心，采用系统字体、半透明玻璃、低饱和灰绿配色和 200–400ms 交互过渡，不包含气象图案。

## 启动

需要 **Node.js 20.19+** 与 **Python 3.10+**。本机可自动识别已有 Python。

在此文件夹双击 **启动.bat**；或者在终端运行：

```powershell
npm install
npm start
```

浏览器打开 **http://127.0.0.1:8765**。首次启动会自动生成前端构建。保持启动窗口打开，按 Ctrl+C 停止服务。

开发模式：`npm run dev`，访问 **http://127.0.0.1:5173**。

如需指定 Python，设置环境变量 `CONJUGAISON_PYTHON` 为可执行文件的完整路径。

## 保留功能

- 必会 / 常用 / 生僻三级词表，原版九份 CSV 数据完整保留。
- 现在时、复合过去时、未完成过去时。
- 掌握程度判断、反向选择、选择题、拼写题；题型可独立开关。
- 原版间隔复习安排、错题记录与删除、已掌握列表及放回生词。
- 动词查找、重音符号模糊匹配、词干提示与学习统计。
- 自动保存与继续学习，保留完整后续题目池，防止恢复时遗漏题目。

## Android 手机安装包

可安装文件：`手机安装包/法语变位器-3.0.5.apk`。复制到 Android 8.0+ 手机打开安装，首次安装按系统提示允许文件管理器的安装来源。已安装旧版时可直接覆盖安装，保留相同的应用数据和签名。

3.0.5：词典同时作为单词本，提供“全部 / 已背”筛选。每个时态有独立的“立即练习”，跳过掌握度判断，直接完成这个词的选择、反向、填空练习，全部答对后计入该时态的已背。普通词表练习进度单独保留。已背词可以再次专练，原掌握日期与已背天数不重置；也可将指定时态“返回单词本”，该词会在对应词表中优先出现，其他时态不受影响。返回操作仅调整所选动词；其他词的当前题目、题型阶段、已答人称和错题重试均保留。放回的词排在当前组之后、后续新词之前，没有进行中的词表则在下次开始时优先安排。

总览中点击“修改目标”可设置每天 1–100 个动词的小目标，默认 3 个。按当天完成的不同动词计数，同一个词多个人称、多种时态或重复练习均不重复增加；完成到期复习也计入当天。判断掌握度时，所有题库动词均附中文常用义。分享内置 15 句中法双语名言，点击“换一句”随机切换，一轮看完前不重复，预览与导出的图片同时更新。

手机版本为独立离线应用：全部九份题库与练习逻辑均随包安装，不需要启动电脑或连接 Python 服务。数据存于手机应用本地，与电脑记录各自独立。

电脑和手机均采用三个动词一组的顺序：先完成本组三个动词的掌握度判断，再加入练习题。同一动词固定按选择 → 反向 → 填空推进，本轮所有人称答对后才进入下一轮。不同动词的题随机穿插；答错的题返回随机队列，保持当前题型，完成本组后再进入下一组。默认本次学习数量改为 3；卡片、字号与间距改为紧凑布局。

安卓构建源码在 `android/`，离线逻辑在 `src/device-core.js`。本机已准备官方 Android SDK Build Tools 35 与平台 35，执行 `npm run build:apk` 可重新生成安装包。本地签名密钥位于已忽略的 `.android-tools/signing/`，后续更新时请保留此目录，不要公开上传。

执行 `npm run test:device` 验证离线引擎，`npx playwright test` 包含桌面与手机离线资源检查。APK 已完成签名和资源校验，目前尚未进行安卓真机安装验证。

## 分享学习记录

点击右上角的分享按钮，或在本次学习完成后点击「分享这次进步」。可生成 1080 × 1440 PNG 卡片，包含累计背词、今日背词、一句随机法语名言、中文释义及作者，另可选择展示今日动词列表。

提供鼠尾草、亚麻纸、浅薰衣、陶土色、深墨绿五套封面；支持从相册选择图片并调整裁切位置。封面与统计都在本机处理，生成卡片不需要联网。法语原文来源记录在「名言出处.md」。

统计按动词原形去重：完整学完某个动词的一套人称变位或标记掌握后，记入累计；当天完成学习或复习，记入今日。同一动词的多个人称和多种时态不会重复增加单词数；放回生词后仍保留历史累计。已有记录仅从可确认的完整掌握记录补计，不虚构缺失的历史。

桌面浏览器可下载 PNG，支持文件分享的浏览器可调起系统分享。安卓 APK 提供原生相册选择、保存位置选择和系统分享面板。没有请求相册的全盘读取权限。

界面增加浅色 / 深色 / 跟随系统外观、近七天学习足迹、按完成动词数统计的可修改每日目标与快捷搜索。初始数据均来自真实记录，不使用演示统计。

## 数据与原项目

原始项目位于相邻的「法语练习2.0」目录，保持不变。`conjugaison_core.py` 与 2.0 完全一致；原 PyQt 界面另存为 `original_gui.py`，安装 PyQt5 后仍可运行。

首次启动会将 2.0 已有的数据文件复制到 3.0 的 `data/`，不会覆盖 3.0 已有记录。随后所有记录仅在本机 `data/` 中更新，保存时保留 `.bak` 备份。可复制整个 `data/` 目录进行备份；不要同时运行多个服务操作同一份数据。

本地服务只监听 `127.0.0.1`，学习数据保存在本机；源码和安装包通过本仓库发布。
